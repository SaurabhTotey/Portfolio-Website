My portfolio website. Is meant to be simple and clean while still displaying some 'personal flavor'.

Built with [Astro](https://astro.build). Useful commands:

- `npm run dev`: start the dev server
- `npm run build`: build the site into `dist/`
- `npm run preview`: serve the built site locally
- `npm run lint`: format with Prettier and lint with ESLint

Deployment is manual: run the "Deploy to GitHub Pages" workflow from the repository's Actions tab. This requires the
repository's Pages source to be set to "GitHub Actions".
